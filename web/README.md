# Mechanic RAG — web UI

Next.js App Router UI and `/api/ask` / `/api/health` for the citation-backed mechanic Q&A path. This folder is not a standalone hosted demo.

**Start here for the full stranger clone path** (Compose Postgres, env, Ollama, fixture ingest, then this app):

→ [`../GETTING_STARTED.md`](../GETTING_STARTED.md)

## Dev (after root setup)

```bash
cd web
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Prefer `pnpm` (matches the repo’s documented path); other package managers are not the supported stranger path.
